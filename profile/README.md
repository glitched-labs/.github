## Glitched: security testing for robots.

[Glitched](https://github.com/glitched-labs/glitched) tells you which known weaknesses affect a robot, checks
them on the robot with passive, connect-only probes, and keeps each one tracked until it's fixed. It's for
robotics engineers, security teams and platform teams who want to know what's exposed before a robot ships -
and to keep knowing after it does.

It matches public threat data - MITRE EMB3D, MITRE ATLAS and NIST's NVD - to *your* robot: the platforms it's
built on (ROS 1 and 2, Unitree, Universal Robots, LeRobot), the ROS distribution it runs and the software in
its SBOM, with a reason for every result. It's written in Python, and its on-site runner uses nothing but the
standard library, so you can read exactly what it does before it runs on your network.

We think robot security gets better when the tools are open: the command line, the threat-intel pipelines,
the local scan UI and the runner are open source under the Apache License 2.0. Contributions, issues and
ideas are welcome - and please report security problems privately.
